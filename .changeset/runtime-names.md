Every function is named by what it does, with one verb for one meaning. A function that returns findings is `validate`, and `check` throws: `validateBindings`, `validateCatalog`, `validatePool`, `validatePortableInteraction` and `validateResponse` (were `checkBindings`, `checkCatalog`, `checkPool`, `checkPortableInteraction` and `checkResponse`), and `checkOptional` (was `optional`). A function that reads a whole document or a form that a standard defines is `read` or `write`: `readCandidateAction`, `writeCandidateAction`, `readView`, `writeView` (were `parseCandidateAction`, `actionToJson`, `viewFromJson` and `viewToJson`), `readModuleResolution` (was `parseModuleResolution`), `readResultsJson` and `writeResultsJson` (were `assessmentResultFromJson` and `assessmentResultToJson`), `readItemStage`, `readWireValue`, `writeWireValue`, `readLomGeneral` and `readNumericRecord` (were `itemStageFromJson`, `fromWireValue`, `toWireValue`, `lomGeneral` and `numericRecord`). Plain data is built: `buildSingle`, `buildContainer`, `buildRecord`, `buildCatMetadata` and `buildSectionData` (were `single`, `container`, `record`, `catMetadata` and `sectionData`). An object with behavior is created: `createReadError` and `createPackageResolvers` (were `readError` and `packageResolvers`), and `createTermConverter` (was `termOf`). A lookup is `find`, a list is `list` and a choice is `select`: `findAttribute` (was `attributeOf`), `listChildElements`, `listChildNodes`, `listDescendantNodes`, `listCatalogs` and `listDependencies` (were `childElements`, `childNodes`, `descendantNodes`, `catalogsFor` and `dependencyClosure`), and `selectModalFeedback`, `selectTestFeedback`, `selectRubricBlocks` and `selectTestRubricBlocks` (were `visibleModalFeedback`, `visibleTestFeedback`, `rubricBlocksFor` and `testRubricBlocks`). What is derived from other values is `derive`, and what follows a reference or settles an effective value is `resolve`: `deriveAnsweredStatus`, `deriveExtensionName`, `deriveHazardExposure`, `deriveInitialResponse` and `derivePciProperties` (were `answeredStatus`, `extensionName`, `hazardExposure`, `initialResponse` and `pciProperties`), and `resolveLaunchUrl`, `resolveModuleConfigurationPaths` and `resolveResourcePath` (were `ltiLaunchUrl`, `moduleConfigurationPaths` and `resourcePath`). The rest: `locateElement` (was `locationOf`), `describeIssue` (was `issueText`), `raceAbort` (was `untilAborted`), `fitsCoordinateCount` (was `coordinateCountFits`) and `rubricScore` (was `scoreFromRatings`). No old name is kept as an alias.

An optional parameter comes in one options object, with its default in the documentation: `findAttribute(element, name, { namespace })`, `buildElement(namespace, name, { attributes, children })`, `buildScoreCoversBlock(outcome, covers, { notes })`, `buildScoringRubricBlock(rubric, { notes })`, `deriveHazardExposure(hazards, { profile })`, `locateElement(element, path, { trail })`, `createReadError(code, message, { location })`, `readNumericRecord(text, { base })`, `readQtiMetadata`, `readResourceMetadata`, `readCurriculumStandardsSet` and `readAccessForAllResource` with `{ path }`, `resolveResourcePath(manifest, resource, { href })`, `selectCard(catalog, support, { language, braille })`, `createTermConverter(terms, { label })` and `raceAbort(promise, { signal })`. The options types are `FindAttributeOptions`, `BuildElementOptions`, `RubricBlockOptions` (with `RubricNotes`), `DeriveHazardExposureOptions`, `LocateElementOptions`, `CreateReadErrorOptions`, `ReadNumericRecordOptions`, `ReadMetadataOptions`, `ResolveResourcePathOptions`, `SelectCardOptions` and `CreateTermConverterOptions`, and `ParseCandidateActionOptions` and `CatMetadataOptions` are `ReadCandidateActionOptions` and `BuildCatMetadataOptions`. A path that is not a string is refused with the message `The option path must be a string`.

`checkArray` refuses an array with a hole, which `forEach`, `map` and `every` skip unseen: `restoreRandom` took `[1, , 2, 3]` for the state `[1, 0, 2, 3]` and continued another generator than the one asked for, and it now throws a `DataError` that names the index of the hole, as every other entry point that checks an array does. `checkBytes`, `checkFinite`, `checkNonNegative`, `checkOptions`, `checkSeed` and `nonNegativeSchema` are no longer exported from `@assesskit/runtime/checks`, which holds what the player shares; the runtime keeps them to itself.
