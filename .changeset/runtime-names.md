Every function is named by what it does, with one verb for one meaning. A function that returns findings is `validate`, and `check` throws: `validateBindings`, `validateCatalog`, `validatePool`, `validatePortableInteraction` and `validateResponse` (were `checkBindings`, `checkCatalog`, `checkPool`, `checkPortableInteraction` and `checkResponse`), and `checkOptional` (was `optional`). A function that reads a whole document or a form that a standard defines is `read` or `write`: `readCandidateAction`, `writeCandidateAction`, `readView`, `writeView` (were `parseCandidateAction`, `actionToJson`, `viewFromJson` and `viewToJson`), `readModuleResolution` (was `parseModuleResolution`), `readResultsJson` and `writeResultsJson` (were `assessmentResultFromJson` and `assessmentResultToJson`), `readItemStage`, `readJsonValue`, `writeJsonValue`, `readWireValue`, `writeWireValue`, `readLomGeneral`, `readDeclaredValue` and `readNumericRecord` (were `itemStageFromJson`, `fromJsonValue`, `toJsonValue`, `fromWireValue`, `toWireValue`, `lomGeneral`, `declaredValue` and `numericRecord`). `parseDuration` reads an ISO 8601 duration and throws (was `parseIsoDuration`). Plain data is built: `buildSingle`, `buildContainer`, `buildRecord`, `buildCatMetadata` and `buildSectionData` (were `single`, `container`, `record`, `catMetadata` and `sectionData`). An object with behavior is created: `createReadError` and `createPackageResolvers` (were `readError` and `packageResolvers`), and `createTermConverter` (was `termOf`). A lookup is `find`, a list is `list` and a choice is `select`: `findAttribute`, `findNextItem`, `findPreviousItem`, `findStandardTemplate` and `findTestPart` (were `attributeOf`, `nextItem`, `previousItem`, `standardTemplateUri` and `partOf`), `listAncestors`, `listChildElements`, `listChildNodes`, `listDescendantNodes`, `listCatalogs`, `listDependencies`, `listOperands` and `listPlanItems` (were `ancestry`, `childElements`, `childNodes`, `descendantNodes`, `catalogsFor`, `dependencyClosure`, `operandsOf` and `planItems`), and `selectModalFeedback`, `selectTestFeedback`, `selectRubricBlocks`, `selectTestRubricBlocks` and `selectScoreCoverBlocks` (were `visibleModalFeedback`, `visibleTestFeedback`, `rubricBlocksFor`, `testRubricBlocks` and `scoreCoverBlocks`). What is derived from other values is `derive`, and what follows a reference or settles an effective value is `resolve`: `deriveAnsweredStatus`, `deriveExtensionName`, `deriveHazardExposure`, `deriveInitialResponse`, `deriveItemFeedback`, `deriveItemResponses`, `derivePciProperties` and `deriveSessionStatus` (were `answeredStatus`, `extensionName`, `hazardExposure`, `initialResponse`, `itemFeedback`, `itemResponses`, `pciProperties` and `resultStatus`), and `resolveItemIdentifier`, `resolveLaunchUrl`, `resolveModuleConfigurationPaths`, `resolveResourcePath`, `resolveSessionControl` and `resolveStandaloneSessionControl` (were `itemIdentifier`, `ltiLaunchUrl`, `moduleConfigurationPaths`, `resourcePath`, `sessionControl` and `standaloneSessionControl`). The rest: `locateElement` (was `locationOf`), `describeIssue` (was `issueText`), `raceAbort` (was `untilAborted`), `fitsCoordinateCount` (was `coordinateCountFits`) and `rubricScore` (was `scoreFromRatings`). No old name is kept as an alias.

An optional parameter comes in one options object, with its default in the documentation: `findAttribute(element, name, { namespace })`, `buildElement(namespace, name, { attributes, children })`, `buildScoreCoversBlock(outcome, covers, { notes })`, `buildScoringRubricBlock(rubric, { notes })`, `deriveHazardExposure(hazards, { profile })`, `locateElement(element, path, { trail })`, `createReadError(code, message, { location })`, `readNumericRecord(text, { base })`, `listPlanItems(plan, { part })`, `readQtiMetadata`, `readResourceMetadata`, `readCurriculumStandardsSet` and `readAccessForAllResource` with `{ path }`, `resolveResourcePath(manifest, resource, { href })`, `selectCard(catalog, support, { language, braille })`, `resolveStandaloneSessionControl({ control })`, `createTermConverter(terms, { label })`, `timeLimits(node, { extra })` and `raceAbort(promise, { signal })`. The options types are `FindAttributeOptions`, `BuildElementOptions`, `RubricBlockOptions`, `DeriveHazardExposureOptions`, `LocateElementOptions`, `CreateReadErrorOptions`, `ReadNumericRecordOptions`, `ListPlanItemsOptions`, `ReadMetadataOptions`, `ResolveResourcePathOptions`, `SelectCardOptions`, `ResolveStandaloneSessionControlOptions`, `CreateTermConverterOptions` and `TimeLimitsOptions`, and `ParseCandidateActionOptions` and `CatMetadataOptions` are `ReadCandidateActionOptions` and `BuildCatMetadataOptions`. A path that is not a string is refused with the message `The option path must be a string`.
