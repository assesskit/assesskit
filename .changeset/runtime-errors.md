`SecurityError` carries the value of the limit it reports as `maximum` (was `value`), beside `limit`, as the limit errors of the sibling libraries do. Every error class takes `ErrorOptions` last, and an error that reports another holds it as `cause`: the `ReadError` of a value that is not in its lexical form, of a document that is not well-formed or not in its encoding, of an include that cannot be read and of compressed data that cannot be inflated; the `DataError` of a file that cannot be read or written, of text that is not JSON and of a value that a custom operator returns; the `ProcessingError` of a pattern or base value that cannot be used. `createReadError` takes the option `cause`. A broken invariant of the element table is an `AssesskitError` (was a plain `Error`).
